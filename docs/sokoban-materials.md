# 推箱子素材说明

项目采用用户截图所示的经典网页仓库番视觉语言：浅米色沙地、橄榄绿色砖墙、橙色交叉木箱、粉红色圆形目标点和蓝衣黑发的小人。

规则与视觉参考：<https://zh.wikipedia.org/wiki/%E5%80%89%E5%BA%AB%E7%95%AA>

基础教学关卡来源：<https://github.com/shunyue1320/sokoban/blob/master/js/mapdata100.js>（`levels` 中的第 1–23、25、30、31 个条目，共 26 关，MIT License）。XSokoban 关卡数据来源：<https://github.com/isdsi/box_pusher/blob/master/levels_data.sok>（选用原版第 31–50 关，共 20 关，MIT License）。两个来源的许可证和归属均保存在 `docs/third-party/`。

运行时没有直接打包维基百科截图、用户截图或来源不明的商业素材。当前素材由 Canvas 2D 离线重新绘制，使用砖墙接缝、沙地颗粒、橙色木箱交叉木条、粉色目标点和蓝衣仓库工人；所有绘制同时用于游戏棋盘、合集卡片和详情页封面。关卡棋盘按 XSokoban 原版文本拓扑绘制，原版横向房间不会为了视觉强行转置；详情页说明和关卡选择强调经典玩法：只能推不能拉、先规划顺序、避免死角、利用回身空间。

通关规则遵循经典《仓库番》：全部木箱进入任意目标点即可通关，箱子没有颜色或目标配对限制。关卡由 26 关基础关卡和 20 关精选挑战关卡组成；来源文件和许可证信息记录在项目关卡数据注释中。基础关卡保留原始拓扑，当前材质只负责重新绘制视觉表现。
