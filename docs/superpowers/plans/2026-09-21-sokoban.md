# 推箱子 Implementation Plan

## 当前交付

推箱子已作为独立的微信小游戏场景接入合集，使用经典《仓库番》规则、26 关基础教学和 20 关精选 XSokoban 挑战布局。运行时由 `games/sokoban/` 自己管理地图解析、触摸、计时、存档和绘制；合集首页只负责详情页和场景路由。

## 已完成

- [x] 导入参考仓库番 26 关作为基础关卡，并从 XSokoban 原版选择第 31–50 关作为 20 关挑战关卡；每关保留章节、编号、推动难度和解法校验数据。
- [x] 规则支持只能推不能拉、任意箱子进入任意目标点、悔棋、重开、静态死格提示和完整存档回放。
- [x] 规则、存档和解法测试覆盖全部 46 关；每关均可按导入解法完成。
- [x] 采用经典木箱仓库视觉：木墙、木地板、木箱、红色目标点和仓库工人。
- [x] 详情页先展示封面和玩法说明，再进入选关或棋局；棋局页保留合集入口和退出按钮。
- [x] 微信小游戏配置排除测试、工具、文档和评审素材，运行时不依赖网络或 WXML/WXSS。

## 来源与维护

维基百科《倉庫番》用于核对游戏规则和经典表达：<https://zh.wikipedia.org/wiki/倉庫番>。基础教学文本来自 `shunyue1320/sokoban` 的 `js/mapdata100.js`；原版关卡文本来自 `isdsi/box_pusher` 的 XSokoban 数据文件。许可证和来源记录在 `docs/third-party/` 与 `docs/sokoban-materials.md`。

关卡数据是发布运行时的静态文件。修改地图时必须同步更新 `tests/sokoban-solutions.json`；原版关卡不得被教学地图覆盖。修改后运行 `npm run sokoban:verify`、`npm test` 和 `npm run check`。
