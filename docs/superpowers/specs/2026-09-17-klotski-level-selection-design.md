# 华容道多布局选择设计

## 目标

在现有“横刀立马”小游戏中加入可选择的经典华容道布局。玩家可以从游戏页选择已核验的布局，查看名称、棋子结构和难度；每个布局拥有独立的规则、通关判定、步数、计时、存档和最佳成绩。

## 资料边界

维基百科“华容道（游戏）”页面作为布局名称和示意图的主要来源。只有能够从页面或可靠的公开资料明确还原棋盘格、棋子尺寸和目标位置的布局才进入可玩列表。仅有模糊图示、名称无法确认或规则不完整的项目进入待整理清单，不凭猜测补齐。

## 设计

关卡数据集中放在 `games/klotski/levels.js`，每个关卡包含 `id`、`name`、`subtitle`、`pieces`、`goal` 和 `source`。规则模块接收关卡对象，不再直接依赖单一 `classic`；验证器根据关卡棋盘尺寸、棋子占格和目标判定状态。默认关卡仍为 `classic`，已有 `klotski.classic.v1` 存档继续可读。

游戏页顶部的“横刀立马”改为可点击的关卡入口。点击后打开选择弹层，列表展示已核验的可玩布局；选择布局后进入对应棋盘，切换时保留各布局进度。存档键使用 `klotski.<levelId>.v1`，当前布局和最近选择项另存为索引键。旧版 `klotski.classic.v1` 直接迁移为新版同名存档，不丢失历史。

渲染器继续复用木质棋盘与棋子材质；关卡的棋盘尺寸、出口和棋子结构由布局对象提供。选择器使用现有 Canvas 弹层，不引入 WXML/WXSS，也不增加运行时依赖。

## 验收标准

1. 默认进入“横刀立马”，已有横刀立马进度和最佳步数可恢复。
2. 选择器可以打开、关闭、切换布局，当前布局名称和副标题同步更新。
3. 每个发布布局通过占格、边界、碰撞、胜利位置和至少一条完整解法验证；无效布局不会出现在可玩列表。
4. 不同布局的步数、计时、悔棋、重开和存档互不污染。
5. 快速拖动、后台切换、窗口尺寸变化和小游戏包检查继续通过。
