## 开发中的游戏：华容道

华容道是本项目的第一个可玩目标。玩家需要移动棋子，为曹操让出通往出口的路径，并尝试用更少的步数完成挑战。

### 第一版计划

- 还原经典华容道棋盘布局
- 支持触摸拖动或点击移动棋子
- 校验棋子移动边界和碰撞规则
- 记录当前步数
- 支持重新开始
- 完成通关判断和结果提示

### 后续迭代

- 增加不同布局和难度
- 保存最佳步数
- 增加移动动画、音效和通关反馈
- 优化小屏设备上的操作体验
